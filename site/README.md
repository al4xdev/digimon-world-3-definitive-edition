# Landing page

A placeholder ("site under construction") until the real landing page is built, served by Cloudflare Pages as
<https://dw3-definitive.pages.dev/>. Static files only: `index.html` and `assets/` (the logo, the icon and the
backdrops are exports of `docs/images/launcher/`).

Publish a change with `wrangler pages deploy site --project-name dw3-definitive --branch main` from the repository
root.
